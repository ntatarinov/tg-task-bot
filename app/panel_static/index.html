      Move to another instance
      
      
      
      
      The database does not run on SQLite and will not be in the archive. Move it with your database's own tools.
      
      
        
        
      1. 
          Download the archive with the code, settings and data.
          
        
            
            
            
          
        
          The archive holds tokens and the whole chat history. Send it only over a secure channel and delete it after installing.
        
        2. 
        
      2. Stop the bot here. Only one instance can run with a token.
        3. 
        
      3. 
          Install on the new instance (Linux, 32 GB of RAM or more for a local model):
          
        unzip digest-bot-*.zip -d digest-bot
cd digest-bot
sh install.sh
        
          If the model runs in the cloud: sh install.sh cloud. A small server is enough then.
        
        4. 
        
      4. 
          Open the panel on the new instance through an SSH tunnel and go through the Check step:
          
        ssh -L 8090:127.0.0.1:8090 user@server
        
          Then http://localhost:8090. The password is the same, it is in the .env file.
        
        5. 
        
      5. 
          Connect the chat. In the Setup section press "Where is the bot" to see where it is. New chat: add the bot there and press "Allow". Unneeded chat: press "Block".
          If the new instance uses another bot, paste its token first and add it to the groups again.
