# Запуск бота на Windows (через облако Groq)

Простая пошаговая инструкция. Бот будет «думать» через бесплатный облачный Groq —
ничего тяжёлого ставить не нужно, компьютер греться не будет.

Что понадобится:
- архив **tg-task-bot.zip** (уже собран на рабочем столе Mac — перенеси его на Windows через флешку, Google Drive или отправь себе в Telegram «Избранное»);
- бесплатный ключ **Groq** (`gsk_...`) — он у тебя уже есть.

---

## Шаг 1. Распаковать архив
1. Скопируй `tg-task-bot.zip` на новый компьютер (например, в папку «Документы»).
2. Нажми на него правой кнопкой → **Извлечь всё** → **Извлечь**.
3. Появится папка **tg-task-bot**. Запомни, где она лежит.

## Шаг 2. Установить Python
1. Открой сайт: **https://www.python.org/downloads/**
2. Нажми жёлтую кнопку **Download Python 3.12** и запусти скачанный файл.
3. ⚠️ **ОЧЕНЬ ВАЖНО:** на первом экране установщика поставь галочку внизу
   **«Add python.exe to PATH»**, потом нажми **Install Now**.
4. Дождись «Setup was successful» и закрой окно.

## Шаг 3. Открыть окно команд в папке проекта
1. Открой папку **tg-task-bot** в Проводнике (внутри должны быть папка `app`, файл `pyproject.toml`).
2. Нажми на **адресную строку** сверху (где путь к папке), напечатай `powershell` и нажми **Enter**.
3. Откроется синее окно PowerShell — все команды ниже вставляй туда (правой кнопкой = вставить), по одной, каждую с Enter.

## Шаг 4. Установить бота (один раз)
```
py -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -e .
```
Последняя команда качает нужные детали (пару минут) — дождись, пока снова появится строка ввода.

## Шаг 5. Вписать ключ Groq
1. В папке `tg-task-bot` открой файл **.env** Блокнотом (правой кнопкой → Открыть с помощью → Блокнот).
2. Найди строчки про LLM и приведи их к такому виду (ключ вставь свой, `gsk_...`):
```
LLM_PROVIDER=openai
OPENAI_API_KEY=gsk_ВСТАВЬ_СЮДА_СВОЙ_КЛЮЧ
OPENAI_MODEL=llama-3.3-70b-versatile
OPENAI_BASE_URL=https://api.groq.com/openai/v1
```
3. Проверь, что есть строка с базой (оставь как есть):
```
DATABASE_URL=sqlite+aiosqlite:///./bot.db
```
4. Строку `BOT_TOKEN=...` **не трогай** — там уже правильный токен.
5. Сохрани файл (Файл → Сохранить) и закрой.

## Шаг 6. ⚠️ Остановить бота на старом Mac
Два бота с одним токеном работать вместе не могут — будут мешать друг другу.
Поэтому на старом Mac останови процесс бота (`pkill -f app.polling`) **или** просто
выключи старый Mac. Только после этого запускай на Windows.

## Шаг 7. Запустить бота
В том же окне PowerShell:
```
.venv\Scripts\python.exe -m app.polling
```
Через несколько секунд появится строка **`Run polling for bot @im_tudushka_bot`** — значит бот работает. 🎉

**Не закрывай это окно** — пока оно открыто, бот работает. Можешь свернуть его.

## Шаг 8. Чтобы компьютер не засыпал
1. **Параметры** → **Система** → **Питание** (или «Питание и батарея»).
2. Раздел **«Экран и спящий режим»** → пункт **«Спящий режим»** поставь **«Никогда»**
   (хотя бы при работе от сети).
3. Если это ноутбук — открой **Панель управления → Оборудование и звук → Электропитание →
   «Действие при закрытии крышки»** и поставь **«Действие не требуется»** (при питании от сети).

---

## Как запустить снова (после перезагрузки компа)
Бот останавливается, если закрыть окно PowerShell или перезагрузить комп. Чтобы поднять снова:
1. Открой папку `tg-task-bot`, в адресной строке напечатай `powershell` + Enter.
2. Выполни:
```
.venv\Scripts\python.exe -m app.polling
```

## Если что-то пошло не так
- Ошибка вроде «python не является командой» → Python поставлен без галочки PATH (Шаг 2.3). Переустанови Python с галочкой.
- Бот пишет «Conflict» → значит где-то ещё работает второй бот (старый Mac). Останови его.
- В остальных случаях — пришли мне текст ошибки из окна PowerShell, помогу.

> Все твои задачи и настройка «дайджест только в SAP СК» уже внутри файла `bot.db` в архиве —
> на новом компе они сохранятся.
